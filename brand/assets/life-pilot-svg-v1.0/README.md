# Life Pilot SVG Asset Library v1.0

## Authority
The Life Pilot repository is the authoritative master location for approved Life Pilot brand assets.
Build Control should hold brand-governance rules and reference the current approved release, not create a competing master.

## Status meanings
- **Approved**: direct approved element or exact locked colour/motif.
- **Approved reconstruction**: vector reconstruction from an approved raster source.
- **Approved composition; font-dependent**: approved logo composition using font-family references. Font files are not embedded.
- **Derived - review required**: reconstructed from the approved Product Ecosystem artwork and must be visually approved before production use.
- **Concept asset - review required**: created to complete the requested library where no separately approved source asset was available.

## Use rules
1. Do not redraw, trace, approximate or restyle an existing approved asset.
2. Do not silently overwrite an asset. Increment the version and preserve the prior file.
3. New assets require an ID, manifest entry, Gary's approval and promotion into the authoritative library.
4. Real Life and Business Life are activated layers, not Core Life Areas.
5. Money is a foundational signal across all four areas, not a fifth Core Life Area.
6. Do not embed or distribute font files.
7. Preserve the approved four-dash order: Deep Teal, Signal Orange, Muted Magenta, Mid Slate.

## Typography
Logo SVGs reference:
- Libre Baskerville (fallback: Georgia)
- DM Sans (fallback: Arial)

No font files are included.
