# DO NOT REDRAW

All Life Pilot logos, icons, colours and design elements must originate from this approved Brand Asset Library.

Do not recreate, trace, approximate, restyle or redraw existing assets.

Where an asset is missing:
1. Raise the need through Build Control.
2. Create one proposed source asset.
3. Assign an asset ID and version.
4. Record the source and status in the manifest.
5. Obtain Gary's approval.
6. Promote the approved asset into the Life Pilot repository.
7. Reference it in implementation tickets.

Deprecated assets must remain traceable and must not be silently deleted.
